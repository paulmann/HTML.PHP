HTML.PHP

SSI and gettext, without a framework

Production-grade PHP 8.3+ template engine in a single file: Apache SSI directives, gettext-compatible i18n, layouts, scoped partials, safe expressions, escape-first security.

What it does

  • Full Apache SSI directive set, including #if and #exec
  • 60+ plural rules and PO/MO/JSON catalogues
  • Escape-by-default with no $GLOBALS in the core

Built with

HTML, PHP, Shell
